**Clear**

|     |     |
| --- | --- |
| Source Form | CLRB |
| Operation | TEMP = B  <br>B = 00 |
| Condition Codes | H - Not affected.  <br>N - Always cleared.  <br>Z - Always set.  <br>V - Always cleared.  <br>C - Always cleared. |
| Description | Accumulator B is loaded with 00000000. Note that the EA is read during this operation. |
| Addressing mode | Inherent |
