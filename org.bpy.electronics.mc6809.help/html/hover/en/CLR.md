**Clear**

|     |     |
| --- | --- |
| Source Form | CLR M |
| Operation | TEMP = M  <br>M = 00 |
| Condition Codes | H - Not affected.  <br>N - Always cleared.  <br>Z - Always set.  <br>V - Always cleared.  <br>C - Always cleared. |
| Description | Location memory is loaded with 00000000. Note that the EA is read during this operation. |
| Addressing mode | Extended  <br>Direct  <br>indexed |
