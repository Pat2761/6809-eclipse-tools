**Logical AND Memory into Register**

|     |     |
| --- | --- |
| Source Form | ANDA    P |
| Operation | R = R & M |
| Condition Codes | H - Not affected,  <br>N - Set if the result is negative; cleared otherwise,  <br>Z - Set if the result is zero; cleared otherwise,  <br>V - Always cleared,  <br>C - Not affected. |
| Description | Performs the logical AND operation between the contents of an accumulator and the contents of memory location M and the result isstored in the accumulator. |
| Addressing mode | Immediate  <br>Extended  <br>Direct  <br>Indexed |
