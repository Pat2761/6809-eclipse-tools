**Equate symbol to a value**

|     |     |
| --- | --- |
| Source Form | &lt;label&gt; EQU &lt;expression&gt; |
| Description | The EQU directive assigns the value of the expression in the operand field to the label. The EQU directive assigns a value other than the program counter to the label. The label cannot be redefined anywhere else in the program. |
